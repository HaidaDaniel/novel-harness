Sample-first workflow (recommended)

Translate one or two chapters first, review them side by side, adjust the book bible/glossary/settings, then explicitly approve before the whole book starts. The CLI can still launch a whole book without this gate.

  1. Create a sample run (first chapter by default, or one/two chapters).
  2. Open the Run and Chapter tabs to review it.
  3. Approve the sample when it looks right.
  4. Launch the whole book from the approved sample.
